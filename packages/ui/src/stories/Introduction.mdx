# COTATO DESIGN SYSTEM

**COde Together, Arrive TOgether**

## 개요

Cotato 디자인 시스템 스토리북입니다.
`@repo/ui` 공통 컴포넌트 라이브러리를 시각화하여 한눈에 확인하고 테스트할 수 있는 카탈로그입니다.

색상 팔레트는 **Design Tokens/Colors**, 타이포그래피는 **Design Tokens/Typography** 페이지에서 확인할 수 있습니다.

## 컨벤션

### 임포트

```tsx
import {Button} from '@repo/ui/components/buttons/Button';
import '@repo/ui/styles.css';
```

### 색상 토큰

Tailwind 클래스에서 `bg-*` / `text-*` / `border-*` 접두사와 함께 토큰명을 사용합니다.

### 타이포그래피

기본 폰트는 **Pretendard**입니다. Tailwind의 `text-*` 유틸리티 클래스로 토큰을 적용합니다.

```tsx
<h1 className="text-h1 font-bold">제목</h1>
<p className="text-body-l">본문 텍스트</p>
```
